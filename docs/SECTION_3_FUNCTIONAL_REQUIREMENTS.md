This file is the filled Section 3 draft for the SRS. It maps prototype screens to Section 2 use cases and the requested groups: 3.1 to 3.9. For screenshots, open the listed prototype URL and capture manually. Protected routes require login with an account from `docs/DEMO_ACCOUNTS.md`.

| AI generation/explanation | Static local messages. | Gemini/API integration, quota, moderation, premium checks. |
| Email | Invitation/reset actions show local messages only. | Email service integration and delivery tracking. |
| Import validation | Static valid/error preview. | Real Excel parser, row validation, duplicate handling, database save. |
| Exam auto-save/timer | Static UI text and local answer state. | Real timer, auto-save, anti-refresh recovery, final submit lock. |
| Report export | Local success message only. | Generate CSV/PDF/XLSX file by selected exam. |
| CRUD persistence | Most create/update/delete actions show local status only. | Database persistence and list refresh after mutation. |
